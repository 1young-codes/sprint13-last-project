# API 서버 켜고 끄기

화면(React)이 부르는 게시글 만들기 API(`serving/api.py`)입니다. 주소와 값은 [docs/api-spec.md](../docs/api-spec.md)를 따릅니다.
서버는 VM 안 `127.0.0.1:8003`에서 서빙 담당 계정으로 돌립니다.

## 켜기 전에

- 그래픽 카드를 약 19.4GB 씁니다(11/27 측정, 보정 모델 포함). 정리표 "GPU 사용 기록" 탭과 디스코드에 켠다고 남깁니다.
- `nvidia-smi`로 다른 작업이 그래픽 카드를 쓰고 있지 않은지 봅니다 (L4 23GB).
- 패키지는 공용 venv(`/data/venv`)에 이미 있습니다. 새로 깔 때는 `serving/requirements.txt`.

## 켜기

```bash
cd ~/sprint13-last-project
export HF_HOME=/data/models/hf_cache CAMERA_ANGLE_CODE_DIR=/data/models/vendor
set -a; . ~/.openai.env; . ~/.gemini.env; set +a
nohup /data/venv/bin/python serving/api.py > /data/outputs/na_sanghun/api.log 2>&1 < /dev/null &
```

- `CAMERA_ANGLE_CODE_DIR`: 깊이 모델(MoGe) 코드 위치. 빠지면 모델을 못 불러와 서버가 켜지지 않습니다.
- `set -a` 줄: 서빙 담당 홈의 키 파일(본인만 읽기)을 환경 변수로 불러옵니다. 키는 저장소와 `/data`에 두지 않습니다. 빠지면 서버는 켜지지만 로그에 경고가 남고, 문구는 모두 "문구를 만들지 못했습니다."로, 해시태그는 빈 목록으로 나갑니다.
- 각도 모델과 보정 모델을 다 불러온 뒤에 요청을 받습니다. 각도 모델 불러오기는 약 1분(11/25 측정, 11/27에는 53.7초), 보정 모델은 3.2초입니다(11/27 측정). 실패하면 서버가 켜지지 않고 로그에 이유가 남습니다.
- 켜졌는지 확인: `curl -s localhost:8003/presets` 가 각도 목록을 돌려주면 됩니다.

모델 없이 켜기 (화면 연결 확인용, 그래픽 카드 안 씀. 각도 모델과 보정 모델을 모두 건너뜁니다. 위의 `cd`, `export`, `set -a` 줄 다음에):

```bash
nohup /data/venv/bin/python serving/api.py --no-models > /data/outputs/na_sanghun/api.log 2>&1 < /dev/null &
```

각도는 모두 "이 각도는 만들지 못했습니다."로 돌려줍니다. 문구와 해시태그는 실제로 만들어서, 요청마다 OpenAI 비용이 듭니다.

## 끄기

```bash
pkill -u "$USER" -f "[s]erving/api.py"
```

`[s]`는 이 명령을 실행한 셸 자신이 같이 꺼지지 않게 하는 표시입니다. 끈 뒤에 `ss -ltn | grep :8003` 이 아무것도 안 나오면 꺼진 것입니다. 기록 탭에 종료 시각을 적고 디스코드에 끝났다고 남깁니다.

## 내 PC에서 부르기

각자 계정으로 SSH 터널을 열면 `http://localhost:8003`으로 부를 수 있습니다. PowerShell에서는 `--` 대신 `--ssh-flag`를 씁니다.

```
gcloud compute ssh <내 계정>@sprint-ai03-team1 --zone=us-central1-c --project=sprint-ai-chunk2-03 --ssh-flag="-L 8003:127.0.0.1:8003"
```

## 걸리는 시간 (11/25 측정, 도미 사진, 각도 3개)

| | 첫 요청 | 두 번째부터 |
| --- | --- | --- |
| 서버 켤 때 모델 불러오기 | 56초 (한 번만) | 없음 |
| 광각 (회전) | 90초 | 44초 |
| 올려다보기, 내려다보기 (3D 이동) | 각 30초 | 각 29초 |
| 요청 전체 | 150초 | 101초 |

- 서버를 켠 뒤 첫 각도만 약 47초 더 걸립니다. 시연 전에 요청을 한 번 보내 두면 첫 사용자가 기다리지 않습니다.
- 그래픽 카드 최대 18.6GB. 깊이 추정은 각도마다 다시 하지만 한 번에 0.2초라 영향이 거의 없습니다.

## 지금 단계에서 비어 있는 것

- 대표 사진은 보정된 사진입니다. 보정이 실패하면 원본을 씁니다. 각도 사진은 보정 전 원본으로 만듭니다.
- 11/27 측정(도미 사진 1024x768): 각도 없는 요청 전체 18.3초(문구 9.3초, 해시태그 0.7초 포함, 보정은 약 8초로 추정), 각도 1개 요청 전체 105.1초(첫 각도 83.7초). 그래픽 카드 최대 19.4GB(1초 간격 샘플).
- 업스케일은 아직 붙이지 않았습니다. 배경 블러가 지워지는 결함을 민기님이 고친 뒤에 붙입니다(11/27 회의 결정).
