# 드리미나 마케팅 스튜디오 실측 기록

2026년 11월 27일에 [마케팅 스튜디오](https://dreamina.capcut.com/ai-tool/marketing-studio)를 브라우저에서 열어 제품 등록과 이미지 생성 요청을 직접 진행했다. 외부 테스트에는 직접 만든 브랜드 없는 세라믹 향초 이미지를 사용했다.

## 제품 광고

1. 마케팅 스튜디오에서 `제품 광고`를 열었다. 스타일과 제품 이미지가 필수로 표시됐다.
2. `Magazine Cover Look` 스타일을 골랐다. 스타일 선택 화면에는 사진 콜라주, 색면 프로모션, 상품 대표 이미지, 제품 디테일 컷 등 목적과 구도가 다른 선택지가 있었다.
3. `제품 추가`를 눌러 기기에서 테스트 이미지를 올렸다. 이미지가 들어가자 `생성` 버튼이 활성화됐다.
4. 생성할 이미지 수를 1장으로 바꿨다. 화면에 선택된 비율과 해상도는 4:3과 2K였다.
5. `생성`을 누르자 요금제 화면이 열렸다. 이 경로에서는 생성 결과가 나오지 않았다.

## 일반 이미지

1. 마케팅 스튜디오에서 `AI 이미지`를 열었다. 스타일, 제품, 프롬프트, 참조, 이미지 수, 비율과 해상도, 모델을 고를 수 있었다.
2. 모델을 `Dreamina Marketing Lite`로 바꾸고 한 줄 제목이 있는 향초 포스터를 요청했다. 이미지 수는 1장으로 설정했다.
3. `제품` → `제품 추가`로 테스트 이미지를 올렸다. 등록 화면에 제품명과 설명을 입력했다. 다른 각도 사진을 추가할 수 있었고, 요소에도 저장하는 옵션은 해제했다.
4. 등록한 제품을 다시 선택하자 `생성` 버튼이 활성화됐다. 버튼을 누르자 요금제 화면이 열렸다.

## 별도 작업 화면

- `포스터 다시 만들기`는 참고 포스터 또는 템플릿과 새 제품을 받는다. 변경 사항은 선택 입력이다.
- `이미지 비율 조정기`는 완성 이미지를 받고 여러 출력 비율을 한 번에 고르게 한다.
- 계정에서 생성이 막혔다. 후보 화면 이후는 아래의 공식 안내와 공개 제작 사례를 대조했다.

## 프로젝트에 적용하는 방식

상품과 문구를 먼저 고정한다. 에이전트는 참고 포스터 또는 새 시안에서 시작하고, 시안을 직접 본 뒤 작업 가이드를 검색한다. 고친 시안은 버전으로 저장하고 이전 결과와 비교한다. 채택한 포스터에만 최종 출력 작업을 적용한다.
